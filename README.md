# Deals Radar Cloud Heartbeat & 24/7 Automation Scheduler

This cloud repository guarantees 100% 24/7 uptime and autonomous execution for the **Smart Deals Radar & Lamha Ecosystem** on Render, Neon PostgreSQL, and Telegram.

## Capabilities:
1. **Zero-Sleep Keep-Alive:** Pings the Render n8n healthcheck (`/healthz`) every 10 minutes from GitHub cloud servers.
2. **Peak Hour Deal Triggers:** Dispatches deals publishing webhooks during prime shopping hours in the UAE and Gulf.
3. **100% Free & Unlimited:** Hosted in a public GitHub repository with unlimited Actions minutes and zero local machine reliance.
